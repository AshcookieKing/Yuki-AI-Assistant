# Юки — ИИ-ассистент с 3D-аватаром для Windows

Аниме-девушка живёт у тебя на рабочем столе: слышит голос, отвечает голосом, управляет компьютером
(мышь, клавиатура, программы, сайты), смотрит на экран, запоминает тебя, поёт и переодевается.
Мозг работает **локально на твоём ПК** — без подписок и ключей.

| | Минимум | Рекомендуется |

## Установка для чайников (15–40 минут)

### Шаг 1. Поставь 4 программы

Скачивай и устанавливай по очереди, везде жми «Далее»:

1. **Python 3.11** — https://www.python.org/downloads/release/python-3119/
   (внизу страницы «Windows installer (64-bit)»).
   ⚠️ В первом окне установщика **поставь галочку «Add python.exe to PATH»**, иначе ничего не заработает.
2. **Node.js (LTS)** — https://nodejs.org/ (большая зелёная кнопка слева).
3. **Ollama** — https://ollama.com/download (кнопка Download for Windows).
4. **Git** (нужен только для пения) — https://git-scm.com/download/win

После установки **перезагрузи компьютер**.

### Шаг 2. Скачай Юки

На странице репозитория нажми зелёную кнопку **Code → Download ZIP**, распакуй архив
в удобную папку, например `C:\Yuki`. Путь лучше без русских букв и пробелов.

### Шаг 3. Запусти установщик

Открой папку и дважды щёлкни **`setup.bat`**.
Он сам проверит программы из шага 1, поставит библиотеки и скачает «мозг» (~8 ГБ).
Окно может долго висеть на одной строчке — это нормально, идёт скачивание.

В конце на рабочем столе появится ярлык **«Юки»**.

### Шаг 4 (по желанию). Пение и живой голос

Дважды щёлкни **`setup_voice.bat`** (~5 ГБ, только для видеокарт NVIDIA).

### Шаг 5. Запуск

Щёлкни ярлык **«Юки»** на рабочем столе (или `start.bat` в папке).
Первый запуск — около минуты: модели загружаются в память. Справа внизу появится девушка.
Если Windows спросит про доступ к микрофону — разреши.

## Как пользоваться

- **Просто говори.** Она отвечает тебе и игнорирует фон — видео, музыку, разговоры с другими людьми.
  Можно начинать фразу с её имени: «Юки, открой Стим».
- **Перебить:** просто начни говорить — она замолчит. Или нажми `Esc`.
- **Перетащить** фигурку мышкой; **колесо** — размер; **короткий клик** — «тык», она отреагирует.
- **Правый клик** по ней или значок в трее — меню: настройки и чат, микрофон, «замолчи», выход.

### Что можно попросить

| Просьба | Что сделает |
|---|---|
| «Открой Стим», «закрой хром» | запустит или закроет программу |
| «Включи на ютубе лофи» | найдёт и включит видео |
| «Нажми кнопку Отправить», «кликни на поиск» | найдёт на экране и кликнет мышкой |
| «Что у меня на экране?» | посмотрит и расскажет |
| «Какая погода в Москве?» | погода и прогноз |
| «Напомни через 10 минут выключить чайник» | напоминание |
| «Спой Imagine Dragons Believer» | найдёт песню и перепоёт своим голосом (если стоит `setup_voice.bat`) |
| «Переоденься в ведьмочку» | наряды: Неко, Ведьмочка, Ангел, Демонесса, Киберпанк, Школьница, Зимняя |
| «Станцуй», «поклонись» | анимации |

## Настройки (правый клик → «Настройки и чат»)

- **Личность** — имя, характер, уровень грубости (0 — вежливая … 3 — без цензуры, с матом).
- **Модель** — мозг (локальная Ollama или бесплатные облака Groq/Gemini/OpenRouter со своим ключом), «умный режим».
- **Память** — что она о тебе помнит, её «дневник личности»; можно править и удалять.
- **Голос** — голос, тон, «лоли»-голос по образцу, сценическое эхо для пения.
- **Слух** — на что реагировать, чувствительность микрофона, перебивание.
- **Доступ к ПК** — выключен / с подтверждением / полный (удаление и выключение ПК всё равно спрашивает).
- **Внешний вид** — наряд, своя VRM-модель (бесплатные — на hub.vroid.com или в программе VRoid Studio).

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| Окно установщика пишет «Не найден Python» | переустанови Python с галочкой **Add python.exe to PATH**, перезагрузи ПК |
| Девушка не появилась | открой `data\server.log` — там причина; проверь, что Ollama запущена (значок ламы в трее) |
| Не слышит | правый клик → «Включить микрофон»; Windows → Параметры → Конфиденциальность → Микрофон |
| Отвечает на видео/музыку | Настройки → Слух → «Только если назвал её по имени» |
| Тормозит | закрой игры и тяжёлые программы — видеопамять общая; в Настройки → Голос выключи «Говорить голосом образца» |
| Антивирус ругается | добавь папку Юки в исключения (она управляет мышью и клавиатурой — это похоже на «бота») |

Все её действия на компьютере записываются в `data\actions.log`.

## Из чего сделана

| Часть | Технология |
|---|---|
| Мозг | Ollama + Qwen3.5 9B (видит экран); агент для действий + персонаж для разговора |
| Слух | Whisper large-v3-turbo (faster-whisper) |
| Голос | Edge TTS / Silero v5 + перенос голоса Seed-VC |
| Память | embeddinggemma (поиск по смыслу), дневник личности, изучение активности |
| Аватар | three.js + three-vrm: 23 эмоции, 57 морфов лица, жесты, танцы, наряды |
| Фигурка | Electron: прозрачное окно поверх всех окон |
| Пение | yt-dlp + Demucs + Seed-VC + сценическая обработка |

Сторонние компоненты скачиваются при установке и распространяются по своим лицензиям:
Silero TTS (CC BY-NC), Seed-VC (GPL-3.0), образцовая VRM-модель (pixiv three-vrm).
Используй чужие голоса и песни только для себя и с уважением к правам авторов.
